Prosjekter utviklet som del av undervisning

Samleside Helse Fonna

Nettside

Bachelorprosjektet, utviklet i samarbeid med Helse Fonna, er et webbasert beslutningsstøtteverktøy for helsepersonell som arbeider med palliative pasienter. Målet var å gjøre relevant informasjon lettere tilgjengelig og gi en tydeligere oversikt over pasientforløpet, fra identifisering til hjemmetid og hjemmedød. Løsningen ble utviklet med HTML, CSS og JavaScript, med fokus på tilgjengelighet, navigasjon og en søkefunksjon på tvers av nettstedet. Prosjektet ble vurdert til karakter A, og ga meg god erfaring med å utvikle brukervennlige løsninger i tett samarbeid med en ekstern oppdragsgiver. Github repositoriet finner du her.

Titanic overlevelse

Maskinlæring

Kan maskinlæring brukes til å forutsi hvem som ville overlevd Titanic? Dette prosjektet ble utviklet som en del av et universitetsprosjekt, hvor vi brukte historiske data fra Titanic til å trene en modell for å forutsi sannsynligheten for overlevelse. Datasettet, hentet fra Kaggle, inneholder informasjon om 891 passasjerer, og ved hjelp av supervised learning og binær klassifisering trente vi en Random Forest-modell som oppnådde en treffsikkerhet på rundt 81 %. Resultatet ble presentert som en interaktiv applikasjon hvor brukeren kan legge inn informasjon om seg selv og få et estimat på hvor sannsynlig det ville vært å overleve Titanic. Se GitHub repositoriet her.

Hotel management system

App og database

Hotellsystem i C#/.NET med tre roller: gjest, resepsjon og service, mot felles Web API og SQL Server. Opprinnelig var det tre ulike UI-teknologier: ASP.NET MVC for booking, WPF for resepsjon og .NET MAUI for service. WPF og MAUI kjører ikke på Mac, så løsningen ble tilpasset: resepsjon og service er egne nettsider mot det samme API-et, og databasen kjører i Docker i stedet for Azure. Du kan se nærmere på koden i GitHub repositoriet her.

Rescue robots

Robotikk

Utviklet et autonomt søk- og redningssystem med to samarbeidende roboter i ROS2, simulert i Gazebo og visualisert i RViz. Systemet bruker LIDAR og kamera for navigasjon og deteksjon av ArUco-markører, og benytter navigasjonsalgoritmer som Wall Following, Bug2 og Depth-First Search (DFS). Robotene kommuniserer via ROS2 topics og services for å koordinere søk og rapportere funn, noe som ga meg praktisk erfaring med koordinering mellom flere autonome enheter. Github repositoriet finner du her.

Park i byen, 3D datagrafikk

Datagrafikk

Interaktiv 3D- og VR-opplevelse utviklet med Three.js, WebGL og WebXR. Prosjektet inneholder prosedyregenerert terreng, bymiljø og vegetasjon, dynamisk vann med refleksjoner og interaktive objekter, og jeg jobbet også med custom shaders og ytelsesoptimalisering. Desktop app

Pokedex

Maskinlæring

Utviklet en maskinlæringsapplikasjon i Python som gjenkjenner Pokémon fra bilder. Modellen er bygget med TensorFlow og EfficientNetB0, trent på et bildedatasett og evaluert på et separat testdatasett, og bruker OpenCV og NumPy til bildebehandling i et grensesnitt utviklet med PySide6. Modellen returnerer den mest sannsynlige Pokémon-arten med tilhørende konfidensnivå. Grafikken i applikasjonen er tegnet i Procreate. Se GitHub repositoriet her.
